- native subagent는 role 필수, panel seat 필수다. 설명 접두어에 의존하지 않는다. 조절 모델 거부 후 원래 설정부터 재시도한다.
- 거부 기록은 부모/모델별 독립 키로 저장한다. 백그라운드 자식의 실패도 retry hook에서 부모의 기록에 반영하고 같은 거부 모델의 자동 재시도를 중지한다.
- 새 작업·수정·후속·재시도는 새 자식이다. 소유한 자식의 이동 비용이 큰 실행 상태가 꼭 필요한 경우에만 재사용하며 모델과 에이전트를 보존한다.
- 원본 호출 제한과 새 개인 모드의 기본 제한을 native metadata에 기록한다.
- 기록, 지속 todo, 프로그램 저장소, native 이벤트, 예약·heartbeat, 지속 모드, 웹훅 routine과 비밀 입력을 구현했다.
- 동반 3개와 native 2개를 포함해 63개 스킬을 등록한다. Benny의 운영 3개 스킬은 원본처럼 dormant pack에 둔다.
- 포팅 중 Freefy의 부모 모델 고정 지침과 검수 소유를 프로필별로 분리해 검증했다. 이후 Freefy dev 정리에서 프로젝트의 스킬 복사본·자체 검수·goal을 제거했다. 관련 실행 증거는 검사 시점의 이력이다.
