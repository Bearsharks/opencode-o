# 사용자 모델 배정

사용자가 2026-11-19에 갱신한 pstack 모델 선택 규칙이다. 새 하위 에이전트를 배정할 때 적용한다.

- 최고난도는 `hardest tasks` 역할의 `openai/gpt-6.2-astra`를 사용한다. 복잡한 동시성·저장 원자성·교차 기능 설계가 해당한다.
- 정말 쉬운 기계적 작업만 `openai/gpt-6-luna`를 사용한다. 판단이 필요 없는 치환·확정 목록 정리처럼 범위와 정답이 이미 고정된 작업이다. 필요한 역할은 그대로 전달하고 사용자가 명시한 이 선택에 따라 native `model`을 Luna로 지정한다. `difficulty`는 `routine`이다.
- Shipping 프라이머리와 두 전담 검수자는 opencode.jsonc의 에이전트별 모델을 사용한다.
- 그 밖의 구현·조사·설명·검수·패널은 `openai/gpt-6.2-sol`을 사용한다. 조사나 검수를 단순 작업이라는 이유 없이 Luna로 낮추지 않는다.

모델 ID와 variant는 현재 catalog에서 확인한다. 기본 예산은 pstack-models.json을 따르며 이 문서는 난이도에 따른 모델 선택만 정한다. 설정 파일의 역할별 모델과 패널 수를 임의로 바꾸지 않는다.

pstack-models.json은 역할별 설정만 지원한다. Luna 선택은 이 지침을 읽은 에이전트가 명시적으로 배정하는 규칙이며 native 자동 난이도 전환 기능이 아니다.

Astra·Luna·Sol은 모두 GPT 계열이다. 별도 에이전트 검수는 가능하지만 서로 다른 계열의 독립 검수로 보고하지 않는다. 다른 계열 모델이 필수인 절차에서 이 사용자 선택으로 검수자를 구성할 수 없으면 NOT RUN을 남긴다. 이를 숨기려고 Claude나 Grok으로 자동 배정하지 않는다.

프로젝트가 별도로 지정한 실제 장치·Studio 전담 모델과 실행 소유·안전 절차는 이 일반 역할 설정으로 변경하지 않는다.
