# 사용자가 승인한 좁은 작업의 모델 예외

이 지침은 이 pstack 프로필의 모델 선택에만 적용한다. 작업 범위나 실행 권한을 추가하지 않는다. 일반 작업은 `pstack-models.json`의 17개 역할 설정을 따른다.

- `recall`의 대화 기록 분할 검색을 위임할 때는 `openai/gpt-6-luna#high`를 사용한다. 기록 구간별 검색과 근거 추출만 맡기며, 전체 맥락 판단과 최종 종합까지 Luna에 넘기지 않는다.
- 사소한 기계적 수정을 위임할 때는 `openai/gpt-6.1-terra#high`를 사용한다. 수정 범위와 변환 규칙이 이미 정해져 있고 제품·설계 판단이 필요 없는 작업에 한정한다. 원인 조사나 새 동작 설계가 필요하면 일반 역할 설정으로 돌아간다.

위 두 예외는 사용자가 명시적으로 승인한 native `subagent.model` 선택이다. 별도의 역할 키를 만들지 않는다. 기존 역할의 `[pstack:...]` 라우팅 접두사를 붙이면 런타임이 역할표 모델을 강제하므로, 이 두 좁은 작업은 해당 예외 모델을 지정한 일반 위임 호출로 실행한다. 이미 시작한 하위 세션의 모델·identity는 변경하지 않는다.

추가 모델이나 fast 변형은 이 예외에 포함되지 않는다. 이 지침은 에이전트가 따르는 선택 규칙이며, 런타임의 새로운 자동 분류 기능이 아니다.
