# 검증 표의 Roblox 예시 행

검증 표 템플릿(`skills/blite-checks/references/template/checks.md`)의 주석에 있던 예시다.

```markdown
| F-03 | 아래로 조준하지 않고 화면 버튼만으로 판을 끝까지 깨고 착지한다 | `tests/stage1.spec.lua › F03_화면_버튼만으로_판을_깨고_착지한다`를 돌리고, 기본 카메라로 한 판을 녹화한다. 판이 모두 사라지고 착지하면 통과 | 녹화는 조준 입력 없이 버튼만 누른 실제 한 판이 끝까지 깨지고 착지하는 결과를 보여 준다. 테스트는 같은 결과가 버튼 입력만으로 나는지 반복해 확인한다 |
```

템플릿 머리말은 관찰 수단의 예로 "각도, 좌표, 횟수"를 들었다.
