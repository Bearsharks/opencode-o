# 조사와 예행

Jot은 가상 앱이다. 다음은 어떤 관찰을 근거로 보존하는지 보여 주며, 기능 통과 기록은 아니다.

## E-01 현재 삭제 동작

`src/server/notes.ts`, `src/server/folders.ts` 조사: 현재 메모 삭제는 즉시 `notes` 행을 없애고, 폴더 삭제는 활성 메모를 '내 메모'로 옮긴다. 이 앱은 텍스트 메모만 지원하며 활성 목록·검색·상세는 모두 `notes`를 읽는다(독립 색인·첨부 저장소 없음). 보관과 복원은 새로 검증해야 한다.

## E-02 티켓 기준선

지원팀 리드가 helpdesk 내보내기에 접근해 기존 '메모 복구' 태그로 CSV를 얻었다. 사용자 제공 `docs/support/2026-10-tickets.csv`에서 10월 5일부터 연속 4주 집계 발췌는 `14, 11, 13, 12`(평균 12.5). 같은 권한·필터로 출시 후 다시 내보낼 수 있음을 확인. H-01의 출처와 관찰 가능성에 사용.

## E-03 관찰 표면

로컬 `tests/e2e/fixtures/users.ts`에서 두 계정을 시드해 로그인과 목록·검색·상세 캡처를 예행했다. 테스트 DB의 `notes`에 읽기 전용 조회가 가능하고 기존 테스트 행과 URL을 대응시켰다. F-01과 F-02 관찰 수단에 사용.

## E-04 시계 예행

기존 `tests/e2e/fixtures/clock.ts`의 밀리초 단위 런타임 시계로 서버를 재시작하지 않고 31일을 전진시켰다. 기존 백그라운드 유지 관리 작업의 관찰 로그에서 가상 시간에 따라 정상 실행 경로가 동작함을 확인했다. 만료 기능 자체나 합격 시간을 구현·검증한 기록은 아니다. F-01의 시각 고정과 F-02의 무조작 시간 진행에 사용.
